# 그림 한꺼번에 뽑기 (make_art.py)

캐릭터 6명의 표정 6가지(36장)와 배경 8장을 명령 한 줄로 뽑는다. 요청은 각자 컴퓨터에서 보내고, 키도 각자 컴퓨터에만 둔다.

## 준비

1. Python 3.10 이상.
2. `pip install pillow` (배경 지우기, 미리보기, 참고 그림 줄이기에 쓴다. 없어도 그림은 받아지지만 Cloudflare에는 참고 그림을 못 보내서 표정마다 얼굴이 달라진다.)
3. 레포 맨 위에 `.env` 파일을 만들고 키를 적는다. 이 파일은 깃에 올라가지 않는다.

```
CLOUDFLARE_ACCOUNT_ID=여기에_계정_ID
CLOUDFLARE_API_TOKEN=여기에_토큰
```

키 받는 곳 (Workers 무료 요금제로 된다):

- dash.cloudflare.com에 가입한다.
- 대시보드의 Workers AI 화면에서 "Use REST API"를 누른다.
- API 토큰: "Create a Workers AI API Token"을 눌러 만들고 복사한다. 직접 만들 때는 Workers AI Read와 Edit 권한을 준다.
- 계정 ID: 같은 화면의 Account ID를 복사한다. Workers & Pages 화면의 Account Details에도 있다.

Gemini 그림 모델(`gemini-nano-banana-2.1`)을 쓰려면 `GEMINI_API_KEY=...`를 적고 `--backend gemini`로 실행한다. 이쪽은 무료 한도가 없어서 결제가 연결된 키가 필요하다. 값은 아래 "한도와 값"에 있다.

## 실행

```
python tools/make_art.py --only astra     한 명만 먼저 뽑아 품질을 본다
python tools/make_art.py                    없는 그림을 전부 뽑는다
```

끝나면 `art/preview.png` 한 장에 전부 모인다. 이 한 장만 보면 된다.

| 하고 싶은 것 | 명령 |
|---|---|
| 요청문만 보기 (요청은 안 보냄) | `python tools/make_art.py --dry-run` |
| 이름과 진행 상황 보기 | `python tools/make_art.py --list` |
| 한 장만 다시 뽑기 | `python tools/make_art.py --only astra:smile --force --seed 2` |
| 캐릭터 한 명을 통째로 다시 | `python tools/make_art.py --only astra --force --seed 2` |
| 배경만 | `python tools/make_art.py --only bg` |
| 배경 지우기만 다시 (요청은 안 보냄) | `python tools/make_art.py --recut` |

- 이미 받은 그림은 건너뛴다. 중간에 끊기거나 하루 한도가 차도 같은 명령을 다시 실행하면 이어진다. Cloudflare의 하루 한도는 한국 시간 오전 9시(00:00 UTC)에 다시 찬다.
- `--seed` 숫자를 바꾸면 같은 요청문으로 다른 그림이 나온다.
- 기준 그림(neutral)을 다시 뽑으면 나머지 표정도 같이 다시 뽑아야 얼굴이 맞는다.

## 결과

```
art/
  preview.png            전체 미리보기
  sprites/<캐릭터>/<표정>.png   배경이 투명한 캐릭터 그림 (768x1152)
  bg/<장소>.jpg          배경 (1280x720)
  raw/                   받은 그대로의 그림 (깃에 올리지 않음)
  manifest.json          어떤 요청문과 씨앗으로 만들었는지 기록
```

## 다른 도구로 뽑은 그림 넣기 (ChatGPT 등)

캐릭터 그림은 이 스크립트로 뽑지 못했다. Cloudflare의 안전 필터가 캐릭터 요청을 걸렀다(아래 "실제로 돌려 본 결과"). 그래서 캐릭터는 ChatGPT 같은 도구에서 직접 뽑아 넣는다.

1. `docs/art-prompts-gpt.md` 의 요청문을 붙여 넣어 그림을 받는다.
2. 받은 그림을 `art/raw/<캐릭터 id>/<표정>.png` 로 저장한다. 예: `art/raw/astra/neutral.png`
3. `python tools/make_art.py --recut` 을 실행한다. 투명 배경 그림은 그대로 두고, 단색 배경 그림은 그 색을 지운 뒤 크기를 맞춰 `art/sprites/` 에 넣는다.

요청문 문서는 `python tools/make_art.py --gpt-doc` 으로 다시 만든다. `tools/art_prompts.json` 을 고쳤으면 꼭 다시 만든다(시험이 검사한다).

## 그림 고치기

요청문은 전부 `tools/art_prompts.json`에 있다. 코드는 건드리지 않는다.

- `characters.<이름>.look`: 그 캐릭터의 외모.
- `faces`: 공통 표정 여섯 가지. 캐릭터마다 다르게 하려면 `characters.<이름>.faces`에 적는다.
- `sprite.style`: 전체 화풍.
- `characters.<이름>.key`: 지울 배경색. 머리나 옷이 초록 계열이면 `magenta`, 보라나 분홍 계열이면 `green`.
- `cut`: 배경 지우기 세기. 사람이 같이 지워지면 `low`를 올리고, 배경이 남으면 `high`를 내린다. 고친 뒤 `--recut`.

## 방식

1. 캐릭터마다 기준 그림(neutral)을 글만으로 한 장 뽑는다.
2. 그 그림을 참고 그림으로 붙여서 표정만 바꾼 다섯 장을 뽑는다. 그래야 같은 얼굴이 나온다.
3. 캐릭터는 단색(초록이나 자홍) 배경으로 뽑고, 코드가 그 색을 지워 투명하게 만든다.
4. 배경은 사람 없이 따로 뽑는다.

기본 모델은 Cloudflare Workers AI의 FLUX.2 klein 4B(`@cf/black-forest-labs/flux-2-klein-4b`)다. 참고 그림은 4장까지 받고, 한 장이 512x512보다 작아야 해서 긴 쪽을 511픽셀로 줄여 보낸다.

`--backend schnell`(`@cf/black-forest-labs/flux-1-schnell`)은 더 싸지만 요청문과 단계 수만 받는다. 참고 그림을 못 받아서 표정마다 얼굴이 달라질 수 있고, 그림 크기도 정할 수 없다. 요청문은 2,048자까지다(지금 가장 긴 요청문이 1,360자).

## 한도와 값

2026-11-13에 공식 문서의 값으로 계산했다. 값은 바뀔 수 있다.

Cloudflare Workers AI는 하루 10,000 뉴런까지 무료다. 한도는 매일 00:00 UTC(한국 시간 오전 9시)에 다시 찬다. 다 쓰면 그 뒤 요청은 오류(번호 3036)가 나고, 스크립트는 거기서 멈춘다.

FLUX.2 klein 4B의 값은 나오는 그림 512x512 한 칸에 26.05뉴런, 참고 그림 512x512 한 칸에 5.37뉴런이다.

| 그림 | 넓이 (512x512 칸) | 넓이에 비례해 셀 때 | 칸을 올려서 셀 때 |
|---|---|---|---|
| 캐릭터 768x1152 | 3.375칸 | 87.9뉴런 | 104.2뉴런(4칸)에서 156.3뉴런(6칸) |
| 배경 1280x720 | 3.516칸 | 91.6뉴런 | 104.2뉴런(4칸)에서 156.3뉴런(6칸) |
| 참고 그림 341x511 한 장을 붙이면 | 0.665칸 | 3.6뉴런 더 | 5.4뉴런 더(1칸) |

- 넓이에 비례해 센다면 한 장에 88에서 92뉴런이고, 하루에 110장쯤 된다. 44장 전체는 약 4,000뉴런이다.
- 문서에는 한 칸이 안 되는 넓이를 어떻게 세는지가 없다. 올려서 센다면 한 장에 104에서 162뉴런이고, 하루에 60에서 95장이다. 44장 전체는 4,700에서 7,000뉴런이다.
- 어느 쪽이든 44장 전체를 하루 안에 한 번은 뽑을 수 있다. 하루에 두 번은 넓이에 비례해 셀 때만 된다(약 8,000뉴런).
- 실제로 쓴 뉴런은 대시보드의 Workers AI 화면에서 본다.

flux-1-schnell의 값은 512x512 한 칸에 4.80뉴런, 한 단계에 9.60뉴런이다. 스크립트는 4단계로 보내므로 단계 값이 38.4뉴런이다. 나오는 그림의 크기가 문서에 없어서 칸 값은 모른다. 1024x1024(4칸)라면 한 장에 57.6뉴런, 하루에 170장쯤이다.

Gemini `gemini-nano-banana-2.1`은 무료 한도가 없다(Free Tier: Not available). 1K 그림 한 장이 1,120토큰으로 0.0336달러이고, 여기에 입력과 생각 토큰 값이 조금 붙는다. 44장이면 그림 값만 약 1.5달러다.

## 문서로 확인한 것과 아직 모르는 것

2026-11-13에 Cloudflare와 Google의 공식 문서를 읽고 맞춘 것은 아래와 같다. Cloudflare klein은 같은 날 진짜 API로도 돌려 봤다(아래 "실제로 돌려 본 결과"). schnell과 Gemini는 가짜 서버로만 시험했다.

- Cloudflare: 모델 이름 둘, 요청 주소, klein의 multipart 칸 이름(prompt, width, height, seed, input_image_0부터 3)과 크기 범위(256에서 1920), schnell의 JSON 칸(prompt, steps), 응답 모양(`result.image`에 base64), 오류 번호(3036 하루 한도, 3040 자리 없음, 3007 시간 초과 등), 값.
- Gemini: 모델 이름, 요청 주소(`v1beta/interactions`), 요청과 응답 모양, 오류 모양, 값.

아직 모르는 것:

- 모델이 단색 배경을 얼마나 잘 지키는지, 표정 다섯 장이 기준 그림과 얼마나 닮는지는 뽑아 봐야 안다.
- 하루에 몇 장까지 되는지는 계산값이다. 한 칸이 안 되는 넓이를 올려서 세는지가 문서에 없다.
- 참고 그림 한도의 문장은 "must be smaller than 512x512"다. 긴 쪽이 딱 512인 그림이 되는지는 알 수 없어서 511로 줄였다.
- schnell이 seed를 받는지가 문서 안에서 엇갈린다(예시는 seed를 보내는데 입력 스키마에는 없다). 스크립트는 seed를 보내 보고, 거절되면 빼고 다시 보낸다.
- 그림이 걸러졌을 때의 번호는 공식 오류 표에 없지만, 실제로는 HTTP 400에 번호 3030, 문장 "Your output has been flagged"가 왔다. 스크립트는 이 번호나 rejected, flagged, nsfw라는 낱말이 보이면 씨앗을 바꿔 다시 해 본다.
- klein의 요청문 길이 한도와 돌려주는 그림의 형식(PNG인지 JPEG인지)은 문서에 없다. 스크립트는 어느 형식이든 받는다.
- 실제와 다른 곳이 있으면 서버가 준 오류 문장이 그대로 찍힌다.

## 실제로 돌려 본 결과 (2026-11-13, Cloudflare klein)

- 배경 8장은 전부 한 번에 나왔다. 한 장에 7-9초. 요청과 응답 형식이 문서대로였고 그림은 JPEG로 왔다. 사람과 글자가 없는 깔끔한 미연시 배경이 나와서 그대로 쓴다.
- 캐릭터 그림은 한 장도 받지 못했다. 요청 6번(요청문 네 가지)이 전부 번호 3030으로 걸러졌다. 요청문에서 "high school student"와 "school"을 빼도 같았다.
- 시험 삼아 "adult"라고 적어 보낸 요청 3번은 통과했다. 다만 다른 조건도 함께 달랐기 때문에 그 낱말이 원인이라고 확정하지는 못했다. 필터를 피할 말을 찾는 시험은 하지 않기로 했다.
- 그래서 캐릭터 그림은 다른 도구에서 직접 뽑아 넣는다(위 "다른 도구로 뽑은 그림 넣기").
